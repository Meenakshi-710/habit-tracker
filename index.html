Habit Tracker is a lightweight Chrome extension that helps you build routines, stay on top of tasks, and (optionally) sync items to your Google Calendar for reminders across devices.

Get it on Chrome Web Store See how it works

Calendar sync is optional and requires Google permission during first-time setup.

Quick look
  • Create habits, tasks, events with reminders
  • Local-first storage by default
  • Optional Google Calendar 2‑way sync
  • Dark mode & keyboard-friendly

Features

Habits with streaks

Stay consistent with visual streaks and completion history.

Tasks & Events

Plan one-offs or schedule events with start times.

Optional Calendar Sync

Connect Google Calendar to mirror items as calendar events. You control what gets synced.

Local-first

Your data is stored in your browser using chrome.storage. No account required.

How it works

  1. Install the extension from the Chrome Web Store.
  2. Add a habit, task, or event.
  3. (Optional) Click “Connect Google Calendar” and grant permission.
  4. Choose which items to sync. You can disconnect any time.

We request only the scopes required for calendar syncing. See Privacy for details.

Permissions & transparency

  • chrome.storage — store your settings and items on your device.
  • identity — authenticate with Google only if you opt into Calendar sync.
  • Calendar API — create/update events you choose to sync.

We comply with the Google API Services User Data Policy, including the Limited Use requirements.
